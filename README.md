# Eye Disease Image Classification

Classification-only learning project on the Mendeley Eye Disease Image Dataset.
The task is: one eye image in, one disease class out. No segmentation, no detection.

This is a classroom exercise, **not** a medical tool.

---

## Quick summary

- We used **only the 5,335 original images**. The pre-made augmented images were
  never downloaded and were not used.
- After duplicate and look-alike cleaning: **4,351 images**.
- Split: **3,038 train / 656 val / 657 test**, with all leakage checks **PASS**.
- Trained **9 CNN models** for 50 epochs plus **SVM** and **Random Forest** baselines.
- Final model chosen by **validation macro F1**: `swin_t`.

| Model | Test accuracy | Test macro F1 | Top-3 | Top-5 |
|---|---:|---:|---:|---:|
| **swin_t** | 0.849 | **0.818** | 0.945 | 0.953 |
| resnet50 | **0.857** | 0.815 | 0.947 | 0.963 |
| densenet121 | 0.836 | 0.813 | 0.954 | 0.970 |
| SVM (ResNet18 features) | 0.799 | 0.722 | — | — |
| simple_cnn | 0.371 | 0.411 | 0.761 | 0.924 |

Full numbers, per-class results, confusion analysis, and limits are in
**[`outputs/reports/FINAL_REPORT.md`](outputs/reports/FINAL_REPORT.md)**.

## Project rules

- Class names are read from the real folder names. They are never hardcoded.
- Original images are only read. Nothing in `Original Dataset` is deleted or edited.
- One seed everywhere: `SEED = 42`.
- All settings live in `src/config.py`.
- Scripts run in order `01_...` to `09_...`.
- PyTorch + torchvision for CNNs; scikit-learn for SVM / Random Forest.

## Run the data preparation locally

Install once:

```bash
pip install -r requirements.txt
```

Then, from the project root:

```bash
python scripts/01_explore_data.py
python scripts/02_find_exact_duplicates.py
python scripts/02_verify_conflicts.py
python scripts/03_find_lookalikes.py
python scripts/03_apply_setting_a.py
python scripts/04_make_splits.py
python scripts/09_prepare_kaggle_package.py
```

Step 9 writes `kaggle_package/eye_data.zip` with 4,351 images and four CSV files
in `eye_data/splits/` (`train`, `val`, `test`, `label_mapping`).

Kaggle rejects square brackets in names, so the folder
`Central Serous Chorioretinopathy [Color Fundus]` is written as
`Central Serous Chorioretinopathy Color Fundus` in the zip. The training code
finds this name automatically; no CSV editing is needed.

## Run the full experiment on Kaggle

1. Verify your phone number in **Settings → Phone verification**.
2. Use **Add Data** to attach the `eye-data` dataset.
3. Set accelerator to **GPU T4/P100** and **Internet: On**.
4. Open `notebooks/eyediseaseclassification1 (2).ipynb`.
5. First run with `SMOKE = True` (2 epochs, tiny data) to check for errors.
6. Set `SMOKE = False`, `SEEDS = [42]`, then **Save & Run All**.
7. Download `results_bundle_seed42.zip` into `notebooks/`.

The notebook trains all nine CNNs one after another, then SVM and Random Forest,
evaluates once on test, and builds the comparison table and result zip.

If the split files are not inside the attached dataset, the notebook downloads
the four CSVs from this GitHub repo automatically.

## Step 6 alone (optional)

`notebooks/kaggle_train.ipynb` is the smaller notebook used before the full one.
It clones this repo, sets the paths, smoke-tests, and can train the models in two
sequential groups:

- light: `simple_cnn`, `mobilenet_v2`, `resnet18`, `efficientnet_b0`
- heavy: `alexnet`, `densenet121`, `resnet50`, `convnext_tiny`, `swin_t`

Set `RUN_LIGHT` / `RUN_HEAVY` to choose which group runs. Do not run models in
parallel on one GPU.

Manual commands are also available:

```bash
python scripts/06_train_cnn.py --model resnet18 --quick
python scripts/06_train_cnn.py --model swin_t --epochs 50
```

`swin_transformer` is accepted as an alias for `swin_t`. Every epoch prints and
saves train/val loss, top-1/3/5 accuracy, and macro F1.

On Kaggle, check the real dataset path first with `!ls /kaggle/input`, then set:

```bash
export EYE_DATA_ROOT=/kaggle/input/<your-dataset>/eye_data
export EYE_OUTPUT_DIR=/kaggle/working/outputs
```

Split CSVs store paths relative to `EYE_DATA_ROOT`, so they work on both Windows
and Linux.
